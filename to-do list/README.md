# To-Do List (Список задач)

Веб-приложение для управления списком задач

## Что умеет сайт

- **Добавлять задачи:** можно ввести название и выбрать дату.
- **Редактировать:** можно изменить название и дату уже созданной задачи.
- **Удалять:** ненужные задачи можно удалить одним кликом.
- **Отмечать выполнение:** если задача сделана, можно поставить галочку, и она зачеркнется.
- **Фильтровать:** можно посмотреть все задачи, только активные или только выполненные.
- **Искать:** есть строка поиска по названию задачи.
- **Сортировать:** задачи можно отсортировать по дате (от старых к новым и наоборот).
- **Менять порядок:** задачи можно перетаскивать мышкой (drag-and-drop), чтобы выстроить их в нужном порядке.
- **Сохранять данные:** все задачи сохраняются в localStorage браузера, поэтому они не пропадают при обновлении страницы или закрытии вкладки.

## Технологии

- HTML5
- CSS3 
- JavaScript
